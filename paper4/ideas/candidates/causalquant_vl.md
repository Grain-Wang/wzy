# CausalQuant-VL

**Research Opportunity / Canary Design (not Paper Candidate).**

CausalQuant-VL studies whether uniform low-bit quantization changes a VLM's behavioral dependence on task-relevant visual evidence, measured by paired counterfactual image interventions, and whether a static dependency-preserving calibration objective can retain the BF16 intervention response. It explicitly excludes runtime routing, mixed-precision search, token allocation, and hardware-budget optimization.

Initial gate: CONDITIONAL GO pending C02. No method implementation is authorized.
